# Support

Use [GitHub Issues](https://github.com/GaiskaSalomon/nsevt/issues) for bug
reports, feature requests, documentation gaps, and reproducible statistical
questions. Include the nsevt and Python versions, operating system, a minimal
script, expected result, and actual result.

The project cannot validate an application's threshold, independence,
measurement quality, or causal interpretation without domain-specific evidence.
Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
